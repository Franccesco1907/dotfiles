# Portable SDD model profiles
Apply the same Gentle AI model-routing policy on macOS, Ubuntu, or WSL2 without copying complete tool configurations.

## Quick path

1. Install Codex, OpenCode, and Gentle AI.
2. Authenticate Codex and OpenCode with OpenAI on the target machine.
3. Let Gentle AI generate the machine-local base configuration.
4. Preview and apply the portable layer:

~~~bash
./ai/model-profiles/apply.sh --dry-run
./ai/model-profiles/apply.sh
~~~

5. Restart Codex and OpenCode.

## What is installed

| Tool | Profiles |
|------|----------|
| OpenCode | quality, quality-fast, dangerous-gentleman, dangerous-gentleman-fast |
| Codex | gentle-orchestrator-quality, gentle-orchestrator-fast, dangerous-gentleman, dangerous-gentleman-fast |
| Codex SDD lanes | sdd-strong, sdd-mid, sdd-cheap and their Fast counterparts |

The quality profile reserves GPT-6 Astra for design, verification, and critical review. Sol handles orchestration and implementation, Terra handles structured planning, and Luna handles mechanical phases. Fast profiles preserve the same reasoning effort while requesting priority processing.

## Usage

In OpenCode, press Tab to select **sdd-orchestrator-quality** or **sdd-orchestrator-quality-fast**. Use **dangerous-gentleman-fast** only for trusted repositories.

In Codex:

~~~bash
codex -p gentle-orchestrator-quality
codex -p gentle-orchestrator-fast
codex -p dangerous-gentleman-fast
~~~

The Dangerous Gentleman profiles disable approvals and use unrestricted filesystem access. They are intentionally unsafe for untrusted repositories.

## Ownership boundaries

The repository owns:

- model IDs;
- reasoning effort;
- Fast or default processing tier;
- portable named profiles.

Each machine owns:

- authentication and account state;
- MCP credentials;
- absolute executable paths;
- histories, sessions, caches, and databases;
- the base configuration generated by Gentle AI.

## Safety and rollback

Before writing, the applicator copies affected files into:

~~~text
~/.dotfiles-backups/model-profiles/<timestamp>/
~~~

Restore the required files from that directory, or rerun Gentle AI to regenerate its base configuration. The applicator is idempotent and can be rerun after Gentle AI upgrades.

## Troubleshooting
If the applicator reports a missing OpenCode or Gentle AI state file, run Gentle AI installation for OpenCode first. Dry-run invokes Gentle AI dry-run and does not change local configuration.
